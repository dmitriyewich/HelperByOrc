[center][size=18][b]HelperByOrc[/b][/size][/center]
[center]Простой биндер команд для SA:MP :good:[/center]

[b]Что это?[/b]
HelperByOrc — это ASI-плагин, который помогает запускать команды и отправлять готовые фразы в чат по нажатию клавиши.

[b]Коротко:[/b]
настроили один раз -> пользуетесь каждый день без лишнего ручного ввода.

[b]Кому подойдёт[/b]
[LIST]
[*]Игрокам, которые часто вводят одни и те же команды.
[*]Тем, кто хочет быстро открывать нужные действия через меню.
[*]Тем, кто хочет меньше рутины и больше удобства в игре.
[/LIST]

[b]Что умеет[/b]
[LIST]
[*]Бинды на клавиши и комбинации.
[*]Быстрое меню биндов.
[*]Удобная работа с чатом и командами.
[*]Группировка биндов по папкам; ручной порядок папок/подпапок: [i]Shift+перетаскивание[/i] строки папки — [b]папка[/b], без [i]Shift[/i] — [b]бинд в папку[/b]. Пока включён [i]поиск папок[/i], DnD папок отключён.
[*]Настройка интерфейса прямо в игре.
[*]Поддержка русской и английской локализации.
[/LIST]

[b]Стабильность интерфейса и фокус[/b]
[LIST]
[*]Курсор и ввод в игре работают согласованно с SA:MP (режим курсора, чат, диалоги).
[*]Бинды и открытие меню плагина по горячим клавишам не срабатывают, если вы печатаете в [i]другом[/i] окне (другой программе), а не в игре: логика привязана к [i]активному[/i] окну GTA.
[*]При открытом UI всё управляется корректно.
[*]Инициализация и остановка плагина вынесены из тяжёлого пути `DllMain` в отдельный bootstrap worker-поток (стабильнее на разных версиях Windows).
[*]До полной инициализации SA:MP overlay откладывает установку WndProc и держит input/cursor pipeline в режиме gate (защита от зависаний на загрузке).
[/LIST]

[b]Установка[/b]
[LIST=1]
[*]Скопируйте HelperByOrc.asi в папку ASI/modloader вашего клиента.
[*]Запустите игру.
[*]Откройте меню плагина (по умолчанию Ctrl + Z).
[/LIST]

[b]Файлы плагина[/b]
[LIST]
[*]HelperByOrc.asi — плагин.
[*]HelperByOrc.json — ваши настройки и бинды.
[*]HelperByOrc.log — лог для диагностики (если нужен).
[/LIST]

[b]Важно[/b]
[LIST]
[*]По умолчанию включено полное логирование ([b]Info[/b]). При необходимости можно переключить уровень в настройках.
[*]Для ранней диагностики запуска/выгрузки есть bootstrap-маркеры в логе: [i][bootstrap] ...[/i].
[*]Для диагностики загрузочных зависаний добавлены probe-маркеры: [i][ui][probe][/i] (Present/EndScene), [i][probe] Refresh begin/end[/i], маркер переключения gate, и [i][probe] shutdown begin/end[/i].
[*]Все основные действия настраиваются через UI внутри игры.
[/LIST]

[b]Сортировка папок (DnD)[/b]
[LIST]
[*]Перетаскивание [b]папок[/b]: клавиша [b]Shift[/b] + перенос. Перетаскивание [b]бинда[/b] в папку: без [b]Shift[/b].
[*]После переноса папки можно отменить один шаг (кнопка в панели папок).
[/LIST]
